# JV Food

App de nutrición de Jere y Vale: menú diario y semanal, compras conjuntas, cocina compartida y progreso.

- `public/`: la app (HTML + JS, sin build).
- `netlify/functions/api.mjs`: API con Netlify Blobs (PIN por usuario, estado compartido).

Se despliega en Netlify conectando este repositorio. No hace falta configurar variables de entorno.
